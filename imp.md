1. INTRODUCTION
------------------------------------------------------------
AIMEDIXAL est un moteur d’analyse multimodale conçu pour
quantifier objectivement les symptômes moteurs de la maladie
de Parkinson. Le système repose sur une architecture
souveraine, exécutée entièrement en local, et combine :

• Analyse biomécanique (accélérométrie 3–12 Hz)
• Analyse acoustique (dysarthrie)
• Intégration des métriques cliniques MDS-UPDRS
• Visualisation sémiotique multidimensionnelle
• Preuve physique-cognitive (OMNIA SEALED)
• Gouvernance stricte des données (RGPD / HIPAA / Loi 25)

------------------------------------------------------------
2. CONTEXTE CLINIQUE
------------------------------------------------------------
Les évaluations traditionnelles reposent sur l’observation
visuelle, entraînant :

• Variabilité inter-cliniciens
• Subjectivité de l’interprétation
• Absence de mesure quantitative reproductible
• Difficulté à suivre l’évolution fine des symptômes

AIMEDIXAL répond à ce besoin en fournissant des indicateurs
objectifs, reproductibles et compréhensibles.

3. ARCHITECTURE AIMEDIXAL
------------------------------------------------------------

3.1 Modèle M1 — Signaux Physiques & Acoustiques
• Accélérométrie 3–12 Hz
• Extraction RMS, pic spectral, puissance
• Analyse gyroscopique de la régularité
• Spectrogrammes Mel pour la dysarthrie

3.2 Modèle M2 — Données Cliniques
• Scores MDS-UPDRS III
• Antécédents médicaux
• Données génétiques (optionnel)
• Historique longitudinal

3.3 Performance IA
• Modèles quantifiés TFLite
• Latence d’inférence < 200 ms
• Sensibilité cible : 94 %
• Exécution locale souveraine

7. MODULE Z-CORE (SÉCURITÉ)
------------------------------------------------------------
Architecture Zero-Trust :

• AES-256-GCM
• TLS 1.3
• Audit immuable
• Isolation automatique des segments réseau
• Étanchéité totale des données brutes

Capteurs médicaux validés :
• Accéléromètre clinique
• Gyroscope médical
• Actigraphe certifié
• Interdiction stricte des capteurs mobiles
